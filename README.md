# Retail Sales Data Analysis

## Project Overview

This project performs an end-to-end analysis of retail sales data using Python, Pandas, Matplotlib, and Seaborn.

The objective is to analyze sales performance, customer behavior, product categories, payment methods, and sales trends using data visualization and statistical analysis.

## Dataset

The dataset contains retail transaction records with information such as:

* Invoice ID
* Date
* Customer Type
* Gender
* Product Category
* Unit Price
* Quantity
* Payment Method
* City
* Total Sales
* Customer Rating

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

The project includes:

1. Data loading
2. Data inspection
3. Data cleaning
4. Missing-value analysis
5. Duplicate-value analysis
6. Statistical analysis
7. Product category sales analysis
8. City-wise sales analysis
9. Gender-wise sales analysis
10. Customer type analysis
11. Payment method analysis
12. Monthly sales trend analysis
13. Quantity vs. sales analysis
14. Customer rating analysis
15. Correlation analysis
16. Top transaction analysis

## Visualizations

The project contains:

* Sales by product category
* Sales by city
* Sales by gender
* Payment method distribution
* Sales by customer type
* Monthly sales trend
* Quantity vs. total sales scatter plot
* Customer rating distribution
* Correlation heatmap

## Key Objectives

The main objectives are to:

* Understand overall retail sales performance
* Identify high-performing product categories
* Compare sales across cities
* Analyze customer purchasing patterns
* Understand payment preferences
* Study sales trends over time
* Identify relationships between numerical variables

## Conclusion

This project demonstrates how Python-based data analysis can be used to transform raw retail transaction data into meaningful business insights.

The analysis helps understand sales performance, customer behavior, product demand, payment preferences, and trends that can support data-driven retail analysis.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or Jupyter Notebook.
3. Make sure `sales_data.csv` and `retail_sales_analysis.ipynb` are in the same folder.
4. Install the required libraries if necessary:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

5. Open `retail_sales_analysis.ipynb`.
6. Run the notebook cells from top to bottom.
